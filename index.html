Selected work

Question bank import: 5 min → 15 s

Question Management Bank, Node.js

A synchronous route that processed 10,000+ exam question documents blocked the Node.js event loop for five minutes. I rewrote it as an asynchronous pipeline that splits the documents into chunks and processes them in parallel. It now finishes in about 15 seconds, and the API stays responsive while it runs.

An attendance grid with 1,500+ cells

Attendance Control App, React, Next.js

The attendance screen rendered every cell at once and lagged on each click. Virtualizing the table so that only the visible rows render removed the lag.

Tenant isolation and runtime RBAC

IBMS, NestJS, PostgreSQL

IBMS (Intelligent Business Management System) is a multi-tenant business-management SaaS, in development to be sold to outside organizations. After mapping the domain with event storming, I gave each organization its own database schema and built an RBAC system whose roles and permissions are configured at runtime instead of in code.

An internal Jira/Asana/Miro, as a modular monolith

Padmasana, NestJS, Socket.IO, Kubernetes

The organization wanted a project and collaboration tool shaped around its own workflows. I modelled the domain with event modeling and built it as a modular monolith, with module boundaries enforced at the schema level and Socket.IO for real-time collaboration. Each module's consumers run as their own Kubernetes Deployment, so modules scale separately without the overhead of a full microservices split.
