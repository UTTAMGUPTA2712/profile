03. Engineering "Saves"

System Optimization

The 95% Latency Kill (Question Management Bank)

The Problem

A synchronous route processing 10k+ exam/assessment question documents was blocking the Node.js event loop for 5 minutes (300 seconds).

The Solution

Refactored to an asynchronous, parallelized chunk-processing pipeline with MongoDB field-level encryption so direct DB access never exposes readable PII.

95% REDUCTION

Processing time dropped from 300 seconds to 15 seconds.

Frontend Scalability

The "1500-Cell Problem" (Attendance Control App)

The Problem

Data-heavy attendance-tracking screens with 1,500+ clickable/anchor-based cells were causing DOM lag and interaction latency.

The Solution

Implemented table virtualization in React.js/Next.js, rendering only visible rows to cut DOM overhead.

PERFORMANCE STABLE

Massive reduction in DOM nodes and stable "Time to Interactive" (TTI).

The Solution

Domain Modeling

The Problem

The org needed an internal project/task-management and collaboration tool adapted to its own workflows — functionally comparable to Asana, Miro, and Jira.

The Solution

MODULAR MONOLITH
